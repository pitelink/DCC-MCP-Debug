# commandPort 安装说明

> 触发条件：用户说"**安装DCC连接器**"时安装本连接器。
>
> **优先用自动安装**，不用手工复制：
> * MCP 工具 `dcc_install_connector`（先带 `dry_run: true` 预演）
> * 命令行 `dcc-cli mobu install-connector` / `dcc-cli max install-connector`
>
> 它会调用目标 DCC 自带的独立解释器（`mobupy.exe` / `3dsmaxpy.exe`）问出 **Python 版本**和
> **sys.path**，据此挑对应的 `.pyd`、并选对 site-packages 层——MotionBuilder 各版本有两层
> site-packages、都在 sys.path 上，靠"哪个目录存在"判断会装错层。它读的是目标机器上的真实值，
> 所以不需要下面那些对照表。
>
> 下面手工步骤和对照表是**兜底/参考**：自动安装失败（例如解释器不在预期位置、或版本不在支持范围）
> 时照它手工做。文中的**通用规则/相对路径**部分已经查过 Autodesk 官方文档核实过，可以直接照抄；
> 但**具体到某台机器的绝对路径（盘符、安装目录）**必须先在那台机器上现查（用 `dir`/`ls` 确认对应
> 版本装没装、装在哪个盘），不要凭经验假设某个盘符或路径。

## commandPort 是什么

`commandPort` 是一个编译好的 Python 扩展模块（每个 Python 版本一份 `.pyd`），DCC 软件启动时
通过一个小的启动脚本 `import commandPort` 把它加载进去，加载后会在本地开一个 TCP 端口
（**端口号 = 该 DCC 进程自己的 PID**），把收到的文本当 Python 代码 `exec()` 执行。
[../../SKILL.md](../../SKILL.md) 里记录的"黑盒 TCP 执行入口"就是这个模块——本文档就是把它装到
新的 DCC 软件/新的版本里去的说明。

本包 `plugin/` 目录里（即本文档同目录）的文件：

| 文件 | 用途 |
|---|---|
| `commandPort.cp37-win_amd64.pyd` | Python 3.7 用 |
| `commandPort.cp39-win_amd64.pyd` | Python 3.9 用 |
| `commandPort.cp310-win_amd64.pyd` | Python 3.10 用 |
| `commandPort.cp311-win_amd64.pyd` | Python 3.11 用 |
| `commandPort.pyd`（无版本后缀） | Python 2.7 用 |
| `commandPortStartup.py` | 内容 `import commandPort`，给 MotionBuilder（Python 启动脚本机制）用 |
| `commandPortStartup.ms` | 内容 `python.Execute "import commandPort"`，给 3ds Max（MAXScript 启动脚本机制）用 |
| `commandPort.mod` | Maya 模块声明（放在 `<安装目录>\modules\` 下，配合模块目录里的 `userSetup.py`） |

## 通用规则：要不要改文件名

- **目标环境是 Python 2.7**：必须把对应 pyd 复制过去后**改名为不带任何后缀的 `commandPort.pyd`**
  （Python 2.7 没有 PEP 3149 风格的带标签扩展名识别机制，改了名字才能被 `import commandPort` 找到）。
- **目标环境是 Python 3.x**：**不要改名**，直接把 `commandPort.cpXY-win_amd64.pyd` 原样复制过去
  （Python 3 的导入机制能识别 `模块名.cpXY-平台.pyd` 这种带 ABI 标签的文件名）。

## 3ds Max 各版本安装规则（相对路径）

下表路径均相对于该版本的 3ds Max 安装目录（例如 `<安装目录>\python\Lib\site-packages`），
具体安装目录在哪个盘要在目标机器上现查（`dir "C:\Program Files\Autodesk"` 之类）。

| 版本 | 内嵌 Python | commandPort 文件（**不改名**除非标注） | site-packages 相对路径 | MAXScript 启动脚本相对路径 |
|---|---|---|---|---|
| 2014 | 无内嵌 Python | — 装不了 — | — | — |
| 2018 | 2.7 | `commandPort.pyd`（**需改名**） | `python\Lib\site-packages` | `scripts\Startup` |
| 2019 | 2.7 | `commandPort.pyd`（**需改名**） | `python\Lib\site-packages` | `scripts\Startup` |
| 2020 | 2.7 | `commandPort.pyd`（**需改名**） | `python\Lib\site-packages` | `scripts\Startup` |
| 2021 | 默认 3.7.6（可用环境变量 `ADSK_3DSMAX_PYTHON_VERSION=2` 切回 2.7） | `commandPort.cp37-win_amd64.pyd`（3.7 侧不改名）；如需兼容 2.7 场景另放一份改名的 `commandPort.pyd` 到 2.7 侧 | 3.7 侧：`Python37\Lib\site-packages`；2.7 侧（备用）：`python\Lib\site-packages` | `scripts\Startup` |
| 2022 | 3.7.9 | `commandPort.cp37-win_amd64.pyd`（不改名） | `Python37\Lib\site-packages` | `scripts\Startup` |
| 2023 | 3.9.7 | `commandPort.cp39-win_amd64.pyd`（不改名） | `Python\Lib\site-packages` | `scripts\Startup` |
| 2024 | 3.10.8 | `commandPort.cp310-win_amd64.pyd`（不改名） | `Python\Lib\site-packages` | `scripts\Startup` |
| 2025 | 3.11.4 | `commandPort.cp311-win_amd64.pyd`（不改名） | `Python\Lib\site-packages` | `scripts\Startup` |

启动脚本目录来源：Autodesk 官方文档确认 3ds Max 有系统级 `<安装目录>\scripts\Startup`（所有用户/
会话启动时自动执行，2014-2025 机制不变）和用户级 `%LOCALAPPDATA%\Autodesk\3dsMax\<年份> - 64bit\
<语言>\scripts\startup` 两条路径，装的时候优先用系统级路径。

## MotionBuilder 各版本安装规则（相对路径）

下表路径均相对于该版本的 MotionBuilder 安装目录。

| 版本 | 内嵌 Python | commandPort 文件（不改名） | site-packages 相对路径 | PythonStartup 相对路径 |
|---|---|---|---|---|
| 2020 | 2.7 | `commandPort.pyd`（**需改名**） | `bin\x64\python\site-packages\`（注意**没有** `Lib` 这层） | `bin\config\PythonStartup\` |
| 2023 | 3.9.7 | `commandPort.cp39-win_amd64.pyd` | `bin\x64\python\Lib\site-packages\`（注意**有** `Lib` 这层） | `bin\config\PythonStartup\` |
| 2024 | 3.10 | `commandPort.cp310-win_amd64.pyd` | `bin\x64\python\site-packages\`（**没有** `Lib` 这层） | `bin\config\PythonStartup\` |
| 2026 | 3.11 | `commandPort.cp311-win_amd64.pyd` | `bin\x64\python\Lib\site-packages\`（**有** `Lib` 这层） | `bin\config\PythonStartup\` |

**注意坑点**：MotionBuilder 的 site-packages 路径深度不统一，不同版本各自也存在"另一层"目录，
但那层通常装的是 pip 装的第三方包或 Autodesk 自带的 OpenGL/PySide2，不是 commandPort 该放的地方——
复制前务必对照上表确认层级，不要看到哪层有 `site-packages` 就默认往那放。

`PythonStartup` 目录机制来源：Autodesk 官方文档（MotionBuilder-SDK Directory Structure）确认
MotionBuilder 启动时会扫描两个 PythonStartup 目录——用户级 `Documents\MB\<版本>\config\
PythonStartup` 和安装目录级 `<安装目录>\bin\config\PythonStartup`，另外可用环境变量
`MOTIONBUILDER_PYTHON_STARTUP` 追加更多路径。这个相对路径写法不随版本号变化。

## Maya 各版本安装规则

Maya 和另外两家都不一样。实测（Maya 2024）**只有一个位置真正生效：用模块机制**。

- **解释器**：`<安装目录>\bin\mayapy.exe`。用它问出真实值：
  `"<安装目录>\bin\mayapy.exe" -c "import sys; print(sys.version_info[:3]); print(sys.path)"`
- **pyd**：按问出来的 Python 版本选（2.7 要改名成 `commandPort.pyd`，3.x 原名），放进 sys.path 里那个 site-packages。
  实测 Maya 2024：Python 3.10.8，site-packages = `<安装目录>\Python\lib\site-packages`（注意是小写 `lib`）。

- **启动脚本用模块机制**，两个文件：
  1. `<安装目录>\modules\commandPort.mod`，内容：
     ```
     + commandPort 1.0 ../plug-ins/commandPort
     scripts: scripts
     PYTHONPATH+:=scripts
     ```
     （语法对照 Maya 自带的 `modules\sweep.mod` / `MASH.mod`）
  2. `<安装目录>\plug-ins\commandPort\scripts\userSetup.py`，内容 `import commandPort`

  `scripts:` 把该目录挂进 `MAYA_SCRIPT_PATH`，`PYTHONPATH+:=` 再挂一份到 `sys.path`，
  Maya 启动时就会执行那里的 `userSetup.py`。

- **实测不生效的位置（别再试）**：
  - `<安装目录>\scripts\userSetup.py`
  - `<安装目录>\scripts\startup\*.mel`（那个目录里 383 个文件全是 Autodesk 自己的 mel，
    是给内部 UI 初始化用的，不是第三方的自动执行入口）
  - 官方文档说的用户脚本目录 `Documents\maya\<版本>\scripts\userSetup.py`
    （出处 "Initializing the Maya Python environment"；位置没错、Security 首选项也没关它，
    但重启后探针标记就是不生成。原因未查明——总之模块机制能用，就用模块机制。）

- **DCC 开着时装不了**：`.pyd` 被进程占用，Windows 不允许覆盖。先关掉 Maya 再装。

`dcc-cli maya install-connector [--pid N] [--dry-run]` 已支持 Maya，优先用它。

## 手工安装步骤（自动安装不可用时的兜底）

针对用户要装的具体 DCC + 版本：

1. 先在目标机器上确认该版本实际装在哪个盘/哪个绝对路径（比如 `dir "C:\Program Files\Autodesk"`），
   再查上面对应的表格行确认 Python 版本 → 该用哪个 pyd 文件 → site-packages 相对路径 → 启动脚本
   相对路径，拼出完整绝对路径。
   更稳的办法是直接问该 DCC 自带的解释器：
   `"<安装目录>\bin\x64\mobupy.exe" -c "import sys; print(sys.version_info[:3]); print(sys.path)"`
   （3ds Max 用 `<安装目录>\3dsmaxpy.exe`）——Python 版本决定用哪个 pyd，sys.path 里第一个
   `site-packages` 决定该装哪一层。
2. 复制 pyd：从本包 `plugin/` 里对应文件复制到目标 site-packages 路径。Python 2.7 目标需要复制后
   改名为 `commandPort.pyd`；Python 3.x 直接原文件名复制，不改名。
3. 复制启动脚本：3ds Max 复制 `plugin/commandPortStartup.ms` 到目标 `scripts\Startup` 目录；
   MotionBuilder 复制 `plugin/commandPortStartup.py` 到目标 `bin\config\PythonStartup` 目录。
4. 如果目标软件正在运行，需要重启该 DCC 进程后启动脚本才会生效（`import commandPort` 是启动时跑
   一次的）。
5. 装完之后用 `dcc-cli max status`（3ds Max）/ `dcc-cli mobu status`（MotionBuilder）验证 TCP 端口
   是否已经起来（端口号 = 该 DCC 进程新的 PID）。
